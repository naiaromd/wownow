## 1 · วิธีหา Sales Qualified Lead (SQL) ทาง online

**นิยาม SQL (อย่าสับสนกับ lead เฉยๆ):** lead ที่ผ่าน 4 เกณฑ์ — มีงบ · มีอำนาจตัดสินใจ · มีความต้องการจริง · มี timing · (BANT) · เป้าคือคัดคนที่พร้อมคุย demo ออกจากคนที่แค่ดู

**ช่องทาง online ที่หา SQL คลินิกได้ (B2B — เบากว่า อย. เพราะไม่ใช่ DTC):**

| ช่องทาง | วิธีใช้ | ทำไมได้ SQL คุณภาพ |
|---|---|---|
| **Meta/IG Lead Ads** | targeting เจ้าของคลินิก/หมอ (อายุ 30–55, interest: aesthetic/derma business) → ฟอร์ม qualify | เก็บ contact + qualify ในฟอร์มเลย |
| **Google Search** | คีย์: "เครื่อง body contouring", "aesthetic device ราคา", "lymphatic drainage เครื่อง" | intent สูง — คนหาเอง = พร้อมซื้อ |
| **LinkedIn** | targeting Medical Director/เจ้าของคลินิก | B2B gold, คนตัดสินใจอยู่ที่นี่ |
| **Webinar** (มีในแผน KPI แล้ว) | educational "Non-invasive recovery & lymphatic 2025" → คนลงทะเบียน = warm | ลงทะเบียน = แสดงความสนใจจริง = SQL engine ดีสุด |
| **LINE OA** | content → chat qualify → นัด demo | 85% คนไทยใช้ · qualify ผ่านแชตได้ |
| **VDO short (ดูข้อ 2)** | สร้าง inbound + referral | คนที่ทักหลังดู = intent สูง |

**Qualifying script (3 คำถามคัด SQL เร็ว):**
1. คลินิก/สปา มีเคสบอดี้/หน้า/ฟื้นฟู กี่เคส/เดือน? *(need)*
2. เคยดู/ใช้เครื่องกลุ่มนี้ (RF/LPG/HIFU) ไหม งบลงทุนเครื่องอยู่ช่วงไหน? *(budget)*
3. ใครตัดสินใจซื้อเครื่อง + คิดจะเพิ่มเครื่องช่วงไหน? *(authority + timing)*
→ ตอบครบ 3 = SQL → ส่งเข้า demo pipeline

## 2 · VDO short 1 นาที แนวตั้ง → Referral Engine

**แนวคิดของไนน์ (ขยายเป็นระบบ):** ทำ VDO personalized ให้ลูกค้าแต่ละราย → ลูกค้าโพสต์เอง → เกิด referral + social proof → คลินิกอื่นเห็น → inbound

**ทำไมมันทรงพลัง:** ลูกค้า 8 รายเป็นแบรนด์ดัง (Anantara, Amanpuri) — VDO ที่เขาโพสต์เอง = endorsement ฟรีที่น่าเชื่อกว่าโฆษณา BIB เอง

**Format (ล็อกให้ทำซ้ำได้):**
- 9:16 แนวตั้ง · 60 วินาที · สำหรับ Reels/TikTok/Shorts
- โครง: **Hook 3 วิ** (ผล/ปัญหาที่แก้) → **15–40 วิ ประสบการณ์/บรรยากาศคลินิก** → **CTA** ("ทำที่ [คลินิก]")
- **Co-branded:** โลโก้คลินิก + "powered by icoone" เล็กๆ → คลินิกได้ลูกค้าตัวเอง · BIB ได้ให้คลินิกอื่นเห็น

**Referral loop:**
```
BIB ทำ VDO ให้คลินิก A (ฟรี/รวมในดีล)
  → คลินิก A โพสต์ (ได้ลูกค้าตัวเอง + ดูโปร)
    → คลินิก B เห็นว่า "คลินิก A มี icoone แล้วดูดี"
      → คลินิก B inbound หา BIB = SQL ต้นทุนต่ำ
```

**⚠ Guardrail อย. (บังคับ):**
- เป็น "ประสบการณ์รับบริการที่คลินิก" **ไม่ใช่โฆษณาเครื่องรักษาโรค**
- ห้ามคำ: รักษา[โรค] · หายขาด · ดีที่สุด · ลดจาก X เหลือ Y
- ต้องมี disclaimer "ผลลัพธ์ขึ้นกับแต่ละบุคคล / ภายใต้การดูแลของแพทย์"
- Before/After ต้องมี consent เป็นลายลักษณ์อักษร
- ถ้าใช้ KOL/ลูกค้า → ระบุ #ad ถ้า sponsored

**VDO Kit ที่ BIB ควรมี (ทำครั้งเดียว ใช้ซ้ำ):** shot list มาตรฐาน · เพลง/template ตัดต่อ · caption bank ที่ผ่าน อย. · disclaimer template · consent form → ส่งให้คลินิกทำเองได้ หรือ BIB ถ่ายให้ตอน install

**เริ่มจาก:** ลูกค้า 8 รายที่มีอยู่ (โดยเฉพาะ Anantara + Amanpuri = แบรนด์แรง) → ทำ VDO ชุดแรก → เป็น social proof engine ทันที

## 3 · Russian Persona Playbook — ICP ที่ inbound มาเอง

**Persona:** คนรัสเซีย relocate มาไทย เปิดคลินิก/สปา · **ติดต่อ BIB เอง** (แบรนด์ icoone ติดหัวจากรัสเซีย) · Russia-quality support มีที่ **ภูเก็ต**

**ทำไมเป็น ICP ทอง:**
- **Inbound = ต้นทุนหา lead ≈ 0** (เขามาหาเราเอง)
- แบรนด์ติดหัวแล้ว → ไม่ต้องสร้าง awareness
- มีลูกค้ารัสเซียของตัวเอง = demand มาพร้อมเครื่อง

**ปัญหา (ไนน์เจอจริง):** ไม่มีเครดิตการเงินไทย · ไม่กล้าเสี่ยง model ที่ต้องลงก้อน

**⚠ กับดักที่ต้องระวัง (ตามหลักของไนน์เอง — เกณฑ์คือความเสี่ยง):** "ไม่มีเครดิต + เพิ่ง relocate" = **ความเสี่ยงผิดนัดสูง** — ห้ามปล่อยเครดิตให้เขาแบบง่ายๆ · คำถามที่ถูกไม่ใช่ "ปล่อยหรือไม่ปล่อย" แต่คือ **"ปล่อยแบบไหนที่ความเสี่ยง BIB ต่ำพอ"**

**โครงที่ลดความเสี่ยง *ทั้งสองฝั่ง* สำหรับ persona นี้:**

| กลไก | ทำไม |
|---|---|
| **Rev-share / rent — เครื่องยังเป็นของ BIB** | ไม่ปล่อยกรรมสิทธิ์จนจ่ายครบ · ผิดนัด = ยึดเครื่องคืนได้ |
| **Deposit สูงขึ้นสำหรับ persona นี้** | เขา relocate = มีทุนบางส่วน · deposit = skin in the game |
| **โฟกัสภูเก็ตก่อน** | Russia-quality support อยู่ที่นั่น → เทรน/monitor/ทวงได้ใกล้ชิด |
| **เริ่มเครื่องเก่า/demo (model F)** | ลดทุนจมของ BIB ต่อดีล |
| **Session counter ในเครื่อง = source of truth** | rev-share วัดจากเครื่อง ไม่ใช่คำบอกเล่า + สิทธิ์ audit |
| **Conversion clause** | proof 90 วัน ไม่เดินต่อ = คืนเครื่อง |

→ นี่คือ **Try→Earn→Own เวอร์ชันความเสี่ยงต่ำ** เฉพาะ persona รัสเซีย · ปิดได้โดย BIB ไม่แบกความเสี่ยงเครดิตแทน

**Action:** ทำ **"Russian Clinic Starter Package"** (ภูเก็ต-first · rev-share/rent · เครื่อง demo · สื่อ+เมนูภาษารัสเซีย) — เป็นข้อเสนอสำเร็จรูปสำหรับ inbound รัสเซีย เพื่อไม่ต้องคิดใหม่ทุกครั้ง
