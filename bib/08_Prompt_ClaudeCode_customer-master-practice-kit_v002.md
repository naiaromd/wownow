### 2.2 รวมข้อมูลซ้ำ
จับคู่: เลขนิติบุคคล → ชื่อสะอาด + จังหวัด → เบอร์ → โดเมนอีเมล · ไม่ลบแถวซ้ำ ใส่ `merged_into` + ประวัติ · คู่ไม่แน่ใจเข้าหน้า "รอยืนยัน"
### 2.3 นำเข้าครั้งแรก
ห้องรับของแยกตามแหล่ง (staging) → ทำความสะอาด/จับคู่ → ตารางหลัก · แหล่ง: HubSpot (ส่งออก CSV หรือ API ถามนายก่อน) · Canon v005 · Zoho 4 ไฟล์ · CRM csv · แก้ตามไฟล์ 02 ข้อ 3 · รายงาน: จำนวนก่อน-หลัง · คู่รอยืนยัน · ฟิลด์ที่ขาดต่อกลุ่ม
### 2.4 หน้าทีมขาย
รายการกรองตามกลุ่ม/ขั้น/ลำดับ/จังหวัด · หน้า 1 ลูกค้า (ข้อมูล · คนติดต่อ · ดีล · ประวัติ · ก้าวถัดไป) · Funnel + เป้าเทียบจริง (เป้าอยู่ในตั้งค่า) · ส่งออกอีเมลตามกลุ่มเฉพาะ consent = yes

## 3. Practice Kit (ให้ก่อน แล้วข้อมูลจะตามมา)
3.1 **โปรไฟล์ลูกค้าของคลินิก → เมนูเฉพาะคลินิก (ทำก่อน):** คลินิกกรอกสัดส่วนลูกค้า 10 ประเภท (ไฟล์ 03 ข้อ 4 · รอนายยืนยัน) → กฎจับคู่ 40 โปรแกรมจากคลังที่อนุมัติ → เมนู 3–5 โปรแกรม + ราคาแนะนำ + คำอธิบายง่าย · คลินิกปรับชื่อ/แพ็กเกจ/โปรโมชันในกรอบ BIB · ค่าเครื่องอยู่ในโปรโตคอลผู้ผลิตเท่านั้น · ข้อความอยู่ในข้อบ่งใช้ FDA 510(k) K211272
3.2 **คอนเทนต์จากคลัง + วัดผล:** โพสต์พร้อมใช้ตามเมนู · บันทึกโพสต์ไหน ช่องไหน วันไหน + ยอดดู/ทัก/จอง · รายงานรายเดือนเป็นบทเรียนรวม (ไม่เปิดข้อมูลรายคลินิก)
3.3 **คลังภาพและเทมเพลต:** ภาพจริงของเครื่อง · ป้ายโปรแกรม/สิทธิ์ใช้ · เทมเพลตใส่โลโก้คลินิก
3.4 **บันทึกการใช้เครื่อง (เทราปิสต์ ≤1 นาที บนมือถือ):** วันที่ · โปรแกรม · ประเภทลูกค้า · รหัสลูกค้า · ครั้งที่ในคอร์ส · พึงพอใจ 1–5 · ภาพ (ยินยอมแยก) · เทราปิสต์ได้ชั่วโมงเข้า icoone Certified Therapist + พอร์ตเคส + รางวัลรายเดือน · เจ้าของได้รายงานคืนทุน + สิทธิ์ได้ลูกค้าที่ BIB แนะนำก่อน

## 4. ชั้น AI (ดูไฟล์ 05)
| ตาราง | ใช้ทำอะไร |
|---|---|
| `ai_instructions` | คำสั่งหลักแยกชั้น (แบรนด์ · บริษัท/คลินิก · บทบาท) มีเลขรุ่น · สถานะ draft/active |
| `ai_task_templates` | แม่แบบงาน: ขั้นตอนคิด · รูปแบบคำตอบ · ทำทันที/ทบทวนก่อน |
| `retrieval_rules` | กติกาเลือกการ์ด (แท็ก · สีคำกล่าวอ้าง · สาธารณะ/ภายใน) |
| `knowledge_cards` + `card_versions` | การ์ด 1 เรื่อง · ข้อความต้นฉบับ · ที่มา+หน้า · สี · ผู้อ่าน · วันที่ตรวจ · embedding (pgvector) |
| `review_queue` | ข้อเสนอการ์ดใหม่/แก้ จาก AI หรือคน · ผู้อนุมัติตามประเภท |
| `gap_log` | คำถามที่ AI ตอบไม่ได้ |
- Edge Function ประกอบชั้น 1–5 แล้วเรียกโมเดล · ของที่ออกนอกบริษัทเข้าจอ "ทบทวนก่อนส่ง"
- หน้าผู้ดูแล "คำสั่ง AI": ดู · แก้ · เทียบรุ่น · เปิดใช้รุ่นใหม่ โดยไม่แก้โค้ด
- งานตั้งเวลาสัปดาห์ละครั้ง: สรุปบันทึกเป็นข้อเสนอเข้า `review_queue`
